# v0.1.0-thor-preview.1 — 索尔源码预览版

首个面向 AYN Thor 的源码发布。**开发者预览；无 APK、游戏素材或私有原厂库。**

包含：

- 六个独立 Java 兼容类及视频上传 JNI 源码。
- 固定 Mesa fork 的完整 13 文件修改补丁，包含最新延迟同步资源引用修复。
- 资源准备、视频时钟、后台 Surface 的主机测试，真实 Mesa 生命周期探针。
- 构建工具、带 SHA-256 校验的补丁应用/回滚、来源与第三方许可。
- 脱敏实机摘要：两次开场过场自然播完，音轨欠载均为 0，用户确认返回游戏正常。

本仓库还不是完整游戏移植版的端到端构建工程。原游戏调用点接入、部分私有平台接口、
着色器适配与整套打包流程尚未整理公开；使用自备 APK 也不等于可以直接一键生成游戏。
原版游戏的再分发权利与本项目源码许可相互独立。

平台状态：索尔历史集成版本已完成两轮回归；奥丁 3 尚未实测；未保证全流程稳定或恒定 60 FPS。
